# Migração do Jev IDS e das issues

Origem: [Tucelos/Jev-ids-adversarial](https://github.com/Tucelos/Jev-ids-adversarial).
Destino: [wagnerquadros/trabalho-adversarial](https://github.com/wagnerquadros/trabalho-adversarial).

## Código e histórico

A branch Developer foi importada integralmente para jev-ids/ por git subtree, com seu histórico. Commit de origem: 4a7f2df530bcc5601129414e2c15e1e76e9d1fe7.
O relatório continua na raiz. Diagramas, referências, licença e instruções de contribuição já existentes foram preservados. No README principal, somente os números das referências às issues foram atualizados.
O README, a licença e a documentação originais do Jev IDS permanecem dentro de jev-ids/. Os commits importados pertencem aos autores da base e devem ser distinguidos das contribuições do grupo.

## Issues

Foram copiadas 29 issues, incluindo a issue 29 adicionada depois do planejamento inicial de 28. Títulos, descrições, estados, labels, responsáveis e milestones foram mantidos. As dependências nos textos foram ajustadas para os novos números.
As cópias foram publicadas pela conta autenticada desta migração. Autor e data originais estão identificados no corpo de cada cópia; as issues originais continuam intactas. No momento da exportação, nenhuma issue tinha comentários.
A divisão de trabalho descrita nos textos foi preservada. O quadro Projects da origem e os pull requests existentes não fazem parte desta cópia de arquivos e issues.
